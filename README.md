# Mathosynthesis Project

This project generates mathematical tasks as PDF files from Markdown files based on JSON setup files. It supports multiple languages and customizable options.

## Prerequisites

- **Python 3.6+** installed  
- **Pandoc** installed and available in your system PATH  
- **Lora font** installed (used by default for PDF generation)

### Installing Pandoc

- macOS (Homebrew):  `bash brew install pandoc`
- Windows: Download from https://pandoc.org/installing.html
- Linux (Debian/Ubuntu): `sudo apt-get install pandoc`

## Supported Languages

- English
- German
- Ukrainian
  
(You can add more languages by extending the config and modifying JSON files.)
